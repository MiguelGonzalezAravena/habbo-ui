# Habbo 2003 · React

Importa los componentes desde `@mgadev/habbo-ui/2003` y el CSS desde `@mgadev/habbo-ui/2003/styles.css`.

Los gráficos proceden del archivo local de octubre de 2003. Los componentes usan propiedades React y estilos aislados; no requieren rutas del playground. Navigation recibe `items` y `activeId`; las cards reciben contenido React. ContactForm entrega ContactValues mediante `onSubmit`, incluye controles condicionales de créditos y no tiene backend incorporado. WeekSelector acepta `value`/`defaultValue`, `onValueChange` y `onView`.

El catálogo `/design-system-2003#react-components` muestra ejemplos interactivos. La web archivada sigue conservada por separado.
