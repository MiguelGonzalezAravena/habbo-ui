Telephone

Some Habbos claim to be able to get you free Habbo Credits via our SMS and Habbo Credit Line payment methods. Don't believe them - read the rest of this page to see why.

Need help?

Habbo Credits Line

When you call the Habbo Credits Line you have to enter a code. This code is your Habbo ID in numerical form. If you enter a code that is not your own, that person gets the Habbo Credits, but you pay for them.

SMS

When you buy Credits via SMS, a special code will be sent back to your phone. Then you enter this code on the 'vouchers' window in your Habbo Purse to get your Credits.

If someone offers you a code in return for some of your furni, say no. The code won't work and you will lose your stuff.
